# 📄 PDF Magic Converter

แปลงไฟล์ PDF เป็น **DOCX / DOC / XLSX / XLS / CSV** พร้อม 🧠 **Smart OCR ภาษาไทย** — ทำงานในเบราว์เซอร์ 100% ไฟล์ไม่ถูกอัปโหลดไปเซิร์ฟเวอร์ไหนเลย

**🌐 ใช้งานเลย:** https://tonyy1991.github.io/pdf-magic-converter/

## ✨ ความสามารถ

- 📥 ลากไฟล์ PDF มาวาง เลือกนามสกุลปลายทาง แล้วดาวน์โหลดทันที
- 🧠 **Smart OCR อัตโนมัติ** — ตรวจจับ PDF สแกน/ภาพถ่ายแล้วอ่านตัวอักษรไทย+อังกฤษเอง (Tesseract.js + Otsu binarization + จัดคำไทยด้วยพิกัดพิกเซล)
- 📊 จัดแถว/คอลัมน์ตามตำแหน่งจริงบนหน้ากระดาษ ลง Excel ได้เป็นตาราง
- 📱 ติดตั้งเป็นแอปได้ (PWA) ทั้งมือถือและคอมพิวเตอร์ ใช้ออฟไลน์ได้หลังโหลดครั้งแรก
- 🎨 ดีไซน์ 7 เทคนิค: Glassmorphism, Animated Gradient, Particles, Micro-interactions, 3D Tilt, Dark/Light Mode, Responsive

## 📲 ติดตั้งเป็นแอป

- **Android (Chrome):** เปิดเว็บ → เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มไปยังหน้าจอหลัก"
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
- **Windows (Chrome/Edge):** ไอคอน ⊕ ติดตั้งในแถบ URL
